# Mobile Design

Mobile design guidance lives in [`../ARCHITECTURE.md`](../ARCHITECTURE.md), [`CONTEXT.md`](../CONTEXT.md), and the ADRs under [`adr/`](adr/).

The current Mobile Client design center is a quiet chat-first surface: protected opening, Companion Chat, Account Surface, and gate-driven onboarding. Keep durable message truth in the Agent Runtime and keep local UI state transient.
