# Intentive Marketing

Remotion source for Desktop Client launch and Screen Memory demo videos. This directory was restored from the deleted macOS `demo/` tree and moved to the repository root so marketing assets are owned outside the Swift package.

## Compositions

- `IntentiveDemo` — product overview for the Desktop Client.
- `ScreenMemoryDemo` — Screen Memory search and timeline demo.

## Commands

```bash
pnpm --dir marketing install
pnpm --dir marketing dev
pnpm --dir marketing lint
pnpm --dir marketing exec remotion render IntentiveDemo
pnpm --dir marketing exec remotion render ScreenMemoryDemo
```
