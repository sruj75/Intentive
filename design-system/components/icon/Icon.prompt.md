Renders one of Apex's line icons (sourced from Lucide, MIT-licensed, matched to the reference screens' stroke weight) — use for nav items, stat chips, and any glyph slot.

```jsx
<Icon name="dumbbell" size={20} />
<Icon name="zap" size={18} color="var(--accent)" />
```

Available `name`s: activity, arrow-up-right, check, chevron-left, chevron-right, circle, coffee, droplet, dumbbell, flame, footprints, gauge, heart, layers, mic, plus, route, search, send-horizontal, settings, sparkles, target, user, watch, x, zap.
