Full-pill action button — the only button shape used across Apex; weight and fill communicate hierarchy, never corner radius.

```jsx
<Button variant="accent">Set Routine</Button>
<Button variant="secondary">Dismiss</Button>
```

Variants: `primary` (solid black — main CTA), `accent` (solid orange — energetic/promoted action), `secondary` (light gray fill, for use on light surfaces), `outline` (1px border, for use on dark surfaces like the chat panel), `ghost` (no fill, text only). Sizes: `m` (48px, default), `s` (38px, compact e.g. "Get Started").
