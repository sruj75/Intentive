Circular icon-only button — used for the "Workout / Meal / Water / Sync / Mood" quick-action row and the energy/FAB glyph.

```jsx
<IconButton icon="dumbbell" label="Workout" />
<IconButton icon="zap" label="Energy" variant="accent" />
```

Variants: `surface` (white circle, default — quick-action row), `accent` (solid orange with glow — the energy FAB), `dark` (charcoal — for use on light backgrounds needing contrast). Sizes: `l` 56px, `m` 44px (default), `s` 36px.
